# infra

Terraform (azurerm provider) for the platform's own Azure infrastructure, in the Sweden Central region: Container Apps, Service Bus, Blob storage, Key Vault, Entra External ID, AI Foundry and Application Insights.

There are no Terraform files here yet. The resources, provider pin and remote state arrive in US-1011. Provider credentials, state files and variable files with real values are never committed (see `.gitignore`).
