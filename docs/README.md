# docs

Developer documentation that belongs with the code: how to contribute, how the parts fit together at the code level, and runbooks once there are environments to run.

Planning documents (product backlog, technical specifications, strategy, legal drafts) are kept outside this repository and are not committed here. Client data never belongs in this folder or anywhere else in the repository.

- `contributing.md`: branches, commits, dependencies, tests and the testing-engine boundary.
